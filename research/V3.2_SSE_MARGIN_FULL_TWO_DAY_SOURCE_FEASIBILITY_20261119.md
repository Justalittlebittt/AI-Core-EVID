# V3.2｜融资杠杆需求：上交所逐股两日官方来源全量准入与会计核验（2026-11-19）

## 决策

**`SSE_MARGIN_DETAIL_OFFICIAL_TWO_DAYS_FULL_PAGINATION_PASS / FINANCING_BALANCE_IDENTITY_PASS_AT_WHOLE_YUAN_ROUNDING / INFORMATION_FAMILY_ADMISSIBLE_FOR_FURTHER_STUDY / NO PREDICTIVE ALPHA / NO BUY`**。

真正完成的工作是独立于铜期货、技术指标与财报增长的新信息家族**交易所逐股融资需求**的可获取性测试。融资买入额、融资偿还额、融资余额是有交易所规则定义的业务金额，不是股票主力资金“净流入”；融资余额上升也不自动意味着未来20日股价上涨。本轮**没读取股票价格/后续收益**，没重新打开被冻结的122/8或E层实验。

## 官方来源与经济机制

- 上海证券交易所融资融券明细： https://www.sse.com.cn/market/othersdata/margin/detail/index.shtml 
- 官方交易记录数据接口（来源页面的动态请求）： `https://query.sse.com.cn/marketdata/tradedata/queryMargin.do`，`tabType=mxtype`, `detailsDate=YYYYMMDD`，交易日明确传参。
- 官方说明：`当日融资余额=前日融资余额+当日融资买入额−当日融资偿还额`。交易所提醒**明细仅包含当时融资融券标的证券**，其余退出标的范围的余额可能只进入汇总；不可将2019记录误称为“全部上交所A股”或“全A股样本”。
- 信息机制假说尚待检验：**可观测的融资头寸及融资买入/偿还变化**可能包含尚未完全转移至证券价格的杠杆资金需求压力，也可能只是过去股价上涨后的被动追涨或财务杠杆需求，方向不预设为正；仅有来源数据不证明任何20日超额收益。

## 来源实验记录及修复边界

- 初次请求能读到官方2019条分页元数据，但旧版适配器假设数组格式，实际服务器返回对象字段；首次仅报告`SOURCE_REQUEST_OR_SCHEMA_FAILED`。
- 正确解析后发现服务端单页2000与第二页重复；固定页起止后两天各返回`2000+19=2019`，证明**已申请查询范围内的逐日服务端分页完整**。
- 只改字段/分页及按元衡量差额，**未读取任何未来股票收益，也未执行因子调参**。
- 源数据脚本的成功执行与**整条GitHub工作流结束成功**不同：之前运行因验证脚本字段名与报告列名不一致而失败，最终[GitHub Actions run 44465151388](https://github.com/Justalittlebittt/AI-Core-EVID/actions/runs/44465151388)经独立回查**status=completed、conclusion=success**；此前几次因解析/分页/验证字段不一致失败的run保留为历史，不改写为成功。
- 此处**不能证明**：所有A股公司融资数据均覆盖、官方该时点精确发布时间、历史重新发布版本未修订、股票价格是否已经消化融资变动、预先注册20日收益信号及完整可执行Alpha。

## 对20日预测目标的下一步有效问题

不要把`融资余额增长`简单改成买入规则；它存在**股价涨→融资买入增加**的反向因果，且不是全A股均可参与融资。只有在以下条件满足后，才注册**一条**20日的独立研究：交易所当时标的范围及原始发布时间可获取、免费完整连续日期记录可复现；在每个T日使用T+1开盘前已公开的融资数据，**先控制T日股票自身涨跌、成交量、行业和市值**后，再检验融资信息是否提升后续20日可执行净超额（对照只用过去价格/交易数据）。承认限涨跌停、停牌、最小100股、佣金最低值、真实现金资金。仍无法满足的条件应`SOURCE_NOT_ADMISSIBLE`，不反复换阈值制造新的正均值。
