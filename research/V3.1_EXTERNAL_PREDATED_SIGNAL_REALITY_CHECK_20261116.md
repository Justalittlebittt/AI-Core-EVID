# V3.1｜外部先发布选股信号：真实时间证据与可交易成本核查（2026-11-16）

**目的**：直接推进「可独立验证的、可实际执行、扣费后有优势的 A 股选股信号」，而非新增预测因子/监控系统。本记录是一次有限的第三方来源资格审查及4个固定日的**事后描述性核算**，不是主线增长策略、完整回测、独立OOS、仓位建议或实盘BUY批准。没有访问本仓库2026-11-27固定122/8的未来收益，也没有修改封存样本、阈值或E-layer。

## 为什么关注这个外部项目

外部 GitHub [prince121212/Ashare](https://github.com/prince121212/Ashare) 保存了每日A股选股 JSON。它不是本项目的增长财报策略，而是一个**外部可比较的短期候选生成模型**。部分旧文件的“文件日期”不等于首次提交日期：例如 `public/history/2026-05-06.json` **在2026-06-08才首次进入Git历史**，不能用其最新版本声称5月6日已预先发布并认证全部后来结果。另一仓库 [Wanghaoji123/stock_choice](https://github.com/Wanghaoji123/stock_choice) 的 `data/paper_trading/2026-07-31.md` 首次进入Git历史在2026-08-27、`2026-10-26.md` 在2026-11-12，不能把全部存档无条件当作同期前瞻信号。[huangneng/quant-stock](https://github.com/huangneng/quant-stock) 的早期 `stock_data/selections.json` 记录亦出现2026-05-22统一生成的更早日期数据。

## 核心目标决定与后续执行边界

1. **实际收获**：至少五个特定日期存在可从同日Actions及首次Git版本追溯的未来收益为空的选股记录；证明了可以以“信号先产生、行情后发生”的方法开展**独立来源质量检查**，而不必在过去已观察收益中反复换因子。
2. **尚未成立**：对完整连续时间样本的证据认证、原模型训练/PIT特征审计、同一长期不变规则、实际不涨停可成交、固定仓位/风险预算、基准/经济总收益、费用/滑点后可重复优势与跨年份OOS均未完成。原仓库110个历史信号日、其中2026-07-21至2026-10-29共56个留存日，**绝不能把这五天或四天称为56日完整回测**。
3. **最短有意义的下一项**：若继续此独立挑战者路线，先对上述56个留存日逐日从**首次提交版本**核验源发布时间与Top10原始名单、填充时间与交易日历覆盖；依据外部已经明确的T+1买入/T+2卖出规则，固定买入受限回退、停牌/涨跌停、100股和最低佣金，随后完整报告缺失率、逐月表现、与真正可交易基准的差值。**没有全样本覆盖便不报告优势，更不能训练/调参或选择有利日期。**
4. 此外部模型不是本项目原来的盈利增长主线；除非源审查表明它可以提供**独立的、成本可行的策略机制证据**，不升级为新项目架构，也不覆盖既有增长信号研究。原固定122/8、11月27日端点和V2.8.12前瞻E层继续独立封存。
