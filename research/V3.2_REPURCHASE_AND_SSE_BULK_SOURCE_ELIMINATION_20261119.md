# V3.2｜新信息家族：股份回购 vs 交易所大宗交易的一次性来源准入决策（2026-11-19）

**核心目标**：未来20个A股交易日、扣费且可执行的相对收益的提前预测；现无经过独立检验的Alpha，`NO BUY`。本次只核信息来源，不打开任何股票历史后验收益，不触及2026-11-02冻结122/8、E Fold3/4或2021/22封闭期。

## A. 公司回购真实执行进度：合理机制，但暂不允许扩大研发

**机制**：实际发行人回购可能构成非投机性买入需求；“回购方案”不等于已实际回购，“累计支付金额”不等于仍会有相同比例后续需求。回购也可能发生在股价下跌之后，具有内生性。

上海证券交易所[上市公司自律监管指引第7号——回购股份](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/mainipo/c/c_20250516_10779134.shtml)规定：首次实施回购次一交易日披露、回购股份比例每增加1%按规定期限披露、每月的前3个交易日披露截至上月末进展。此为**事件时间可定义**的正式规则，并不证明交易所存在一个免费、当时完整、历史可逐日封存的全市场发行人回购事件分母。

具体事实例子（不构成市场总体）：2026-11-05唐源电气官方公告（巨潮PDF https://static.cninfo.com.cn/finalpage/2026-11-05/1225659051.PDF ）和2026-10月红塔证券回购进展官方披露均显示此类信息有固定公告口径。**仅发现少数样例不构成无偏回购股票池**。此前CNINFO全市场事件分页已被证实有无法穷尽的日期窗口；不能再次忽略同一分母问题，用“热门回购个股”对已见价格做回溯选股。

**决定**：`EVENT_TIME_PLAUSIBLE / FULL_UNIVERSE_AND_PIT_DENOMINATOR_NOT_CERTIFIED / NO_FULL_20D_EXPERIMENT`。若没有新的完整券商或交易所原始发行人事件清单，不增加爬虫、监测工作流，不进入宣称“回购能赚钱”的测试。

## B. 上交所大宗交易明细：明确来源请求未通过

上交所[现行2026交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)要求每个交易日后公布证券成交申报大宗交易的证券代码、成交量、成交价格及双方会员营业部。折价大宗交易可能反映大股东转让、机构流动性需求；**折价成交价并不是普通投资者可在公开市场买到的价格**。

参考既有开源文档提出官方 `https://query.sse.com.cn/commonQuery.do?sqlId=COMMON_SSE_XXPL_JYXXPL_DZJY`。仅使用预先指定2026-08-14及2026-09-15进行两日来源测验，均为历史已完成交易日。

- 初次请求使用`tradeDate`等猜测字段，虽然HTTP 200，但响应完全相同的500字节、`result=null`、`pageHelp.total=0`。**HTTP200不能作为数据成功凭证**。
- 根据实际返回schema发现`queryDate`字段，调整此一处再用两个完全相同的日期测试。两响应均HTTP200，`queryDate`分别正确回显`20260814`/`20260915`，无`actionErrors`或`fieldErrors`，但均 `result=null`、`pageHelp.total=0`、`pageCount=null`。原始响应SHA256：8月14日 `3e633a8af58bc11cd373cc36fc62fa69798e32cf7dd83f7013c720fd0711b226`；9月15日 `ff9e021503f6c252711087acbd3a78a67c2c99bd35007d6e337c8ebb5999401b`。这些字节不同**只证明请求日期被回显，不证明按该日期返回实际成交记录**。
- [最终 GitHub Actions run 44482344796](https://github.com/Justalittlebittt/AI-Core-EVID/actions/runs/44482344796) 完成且成功，代表**来源探针执行成功**，不是官方明细数据读取成功；初始run `44482100728`同理。源脚本 `scripts/v32_sse_block_trade_source_one_shot.py`，workflow复用 `.github/workflows/v32-cninfo-weekly-denominator-once.yml`，无新常驻轮询。
- 未确认参数`type`、可能旧`sqlId`版本及官网页面当前内部请求；但继续逆向、试参数和构建抓取链**没有已证明的预测价值**，不符合主线减法规则。

**决定**：`HISTORICAL_BULK_CENSUS_SOURCE_NOT_ADMISSIBLE / NO STOCK_OUTCOME_READ / NO BACKTEST / NO BUY`。不能把两天`total=0`声称为没有大宗交易，也不能把`result=null`误当零事件样本。

## 核心任务的消除决策

这轮只验证了两类机制中的**免费、时间可追溯、全样本可获取性**。二者均不够资格开展完整20日收益实验，因此**本轮不创建模型、不检索价格、不生成虚假正Alpha、不重复修复同一页接口**。

后续研究应优先在已有真正完整的证券历史输入（如已通过20日连续与分页验证的上交所融资数据）或官方一次性封闭名单（如指数调整官方全部样本）上，提出**新经济机制且有不同的前瞻/真正未见数据**，而不是换已失败特征/阈值、利用已打开的2025/26价格追溯挑最优规则。现有冻结前瞻只按原方案在到期时评价，不能预先开启结果。

**不把数据管道成功、报告数量、或定期任务绿灯当成用户目标已实现。**
